Cần Khởi Động ONLYOFFICE Document Server
Trình duyệt chưa thể kết nối tới Document Server tại http://localhost:8080.
Để mở trình soạn thảo trên trình duyệt web, vui lòng bật Docker Desktop và chạy lệnh sau trong Terminal:
docker run -i -t -d -p 8080:80 --restart=always onlyoffice/documentserver
💡 Ghi chú: Bản ONLYOFFICE Community Edition trên Docker hoàn toàn miễn phí (0đ bản quyền theo giấy phép AGPLv3).
